# AI 概論初級班

用 AI 工具提升每個人的工作效率 — 公司內訓課程形象網站。

用 Vite + React + TypeScript + Tailwind CSS 打造，透過 GitHub Actions 自動部署到 GitHub Pages。

🔗 https://ericyeh-arch.github.io/demo/

## 開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

## 部署

推送到 `main` 分支後，GitHub Actions 會自動建置並部署到 GitHub Pages（見 `.github/workflows/deploy.yml`）。
